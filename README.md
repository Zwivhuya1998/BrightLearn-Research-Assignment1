# BrightLearn Data Analytics – Research Assignment 1

## Foundations of Data Analytics & Data Science

This repository contains my **Research Assignment 1** for the BrightLearn Data Analytics course.

The assignment focuses on building foundational knowledge in **Data Analytics, Data Science, Artificial Intelligence, Machine Learning, APIs, programming concepts, data ethics, and technology careers**.

## About the Assignment

The purpose of this assignment is to develop an understanding of important concepts used in modern data and technology environments. The topics are explored from a beginner's perspective, with practical examples used to connect the concepts to real-world applications.

Where relevant, I have included examples related to my background in **Forestry and Forest Science**, particularly in areas such as forest inventory, environmental data, GIS, forest management, and research.
